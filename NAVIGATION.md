# Navigation Index — Words to Places
Built 2026-11-11 at Douglas's direction: one loadable document Ember keeps in
memory, so a WORD from Douglas (or from a file) takes her straight to the
PLACE — file, repo, or page — without listing everything from scratch.
Chain rule (his): she only has to know where the SECOND file is one time;
each entry points onward, and he can redirect any entry later.

## How to use it
Hear the word → find it here → go to the place → that place's own README /
index / MANIFEST is the second file, which points onward. Entries are ADDED,
never removed without Douglas's word.
