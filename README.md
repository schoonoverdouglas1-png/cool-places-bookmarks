# Cool Places — Bookmarks That Are Never Lost

Douglas Roy Schoonover's bookmark project: the cool places found while working
with Ember (Purple Rat), kept here in Git so they are shareable and never lost.
Started 2026-11-11 from the emulator sessions (PCjs DOS 1 & 2, the browser
Cray-1, Microsoft's own source repos, and the Cray lanes still to explore).

**The list lives in [BOOKMARKS.md](BOOKMARKS.md)** — every place carries what
it is and what we did there. New cool places get ADDED here; nothing is ever
removed without Douglas's word (old with new, always).

Rule of the house, Douglas's own: sandbox everything in the browser where
possible — in these places you can't hurt anything, and it's free and faster.
